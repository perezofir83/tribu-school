# Escuela Tribu · Zapotal

Interactive 3D design of a 600 m² Bali-style bamboo school (classroom, science lab, dining hall, covered plaza, football/basketball court, vegetable garden, cooling stream and fish pond) on the surveyed terrain of the Zapotal plot, Tonameca, Oaxaca. English / Español.

Includes the residential subdivision (8 lots) and the region to the sea and Ventanilla lagoon.

Textures and sky: Poly Haven (CC0). Terrain: survey + Copernicus GLO-30. Imagery: Sentinel-2 cloudless 2016 by EOX (CC BY 4.0). Map data © OpenStreetMap contributors (ODbL).
